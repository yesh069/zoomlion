# zoomlion.ie

Website for Zoomlion machinery in Ireland, run by O'Regan Plant Sales (authorised distributor, Watergrasshill, Co. Cork).
Lead generation: each machine shows its price, every "Enquire" opens the enquiry form, and WhatsApp/phone/email are on every page.

Next.js (App Router, TypeScript, Tailwind CSS v4), static export to `out/`, hosted on Firebase Hosting.

## Pages

- `/`: home
- `/products/`: all machines with prices and a comparison table
- `/products/<model>/`: machine page (price, overview, features, specs, spec sheet, FAQ, enquiry)
- `/contact/`: contact details, enquiry form, map

## Editing content

- **Machines:** `lib/catalogue.ts` (model, type, price, specs, images). Add a machine there and it appears everywhere: home, products, the menu, the sitemap and llms.txt. Put product shots (cut-out PNG) and site photos (JPG) in `assets/machines/`; the build converts them to WebP in `public/machines/`. Only use manufacturer spec figures (Zoomlion product pages / spec sheets).
- **Contact details:** `lib/site.ts`.
- **Site-wide FAQs:** `lib/faqs.ts`.

## Search & AI visibility (SEO / AEO / GEO)

- Per-page titles, descriptions, canonicals and social cards (`lib/meta.ts`, `public/og.png` generated by `scripts/make-og.mjs`)
- schema.org JSON-LD (`lib/schema.ts`): LocalBusiness dealer, WebSite, Brand, Product with price Offer, BreadcrumbList, ItemList, FAQPage
- Question-led FAQ on every page, with answer-first wording that assistants can quote
- `sitemap.xml`, `robots.txt` (search and AI crawlers explicitly allowed), `llms.txt` summary for AI assistants

## Forms

Set `NEXT_PUBLIC_LEAD_ENDPOINT` to the Google Apps Script web app (`apps-script/`). Until it's set, forms open the visitor's email app with the enquiry filled in.

## Develop & deploy

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # static site in out/
npx firebase-tools deploy --only hosting
```
