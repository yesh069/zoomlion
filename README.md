# zoomlion.ie

Website for Zoomlion machinery in Ireland, run by O'Regan Plant Sales (Watergrasshill, Co. Cork).
Lead generation: each machine shows its price, every "Enquire" opens the enquiry form, and WhatsApp/phone/email are on every page.

Next.js (App Router, TypeScript, Tailwind CSS v4), static export to `out/`, deployed to GitHub Pages by `.github/workflows/pages.yml` on every push to `main` (Firebase config is kept for later).

## Pages

- `/`: home
- `/products/`: all machines with prices and a comparison table
- `/products/<model>/`: machine page (price, overview, features, specs, spec sheet, FAQ, enquiry)
- `/contact/`: contact details, enquiry form, map

## Editing content

- **Machines: edit `data.js` only.** It holds every machine (model, type, price, images, specs, spec sheet) and starts with a plain-English guide to editing, adding and removing machines. The pages map over that list, so a change there updates the homepage, products page, comparison table, menu, footer, machine pages, enquiry form, sitemap and llms.txt. Put images in `assets/machines/` (the build converts them to WebP and records their sizes in `lib/image-sizes.json`) and local spec sheet PDFs in `public/spec-sheets/`. The build type-checks `data.js`, so a typo stops it with the line number.
- **Contact details:** `lib/site.ts`.
- **Site-wide FAQs:** `lib/faqs.ts`.

## Search & AI visibility (SEO / AEO / GEO)

- Per-page titles, descriptions, canonicals and social cards (`lib/meta.ts`, `public/og.png` generated by `scripts/make-og.mjs`)
- schema.org JSON-LD (`lib/schema.ts`): LocalBusiness dealer, WebSite, Brand, Product with price Offer, BreadcrumbList, ItemList, FAQPage
- Question-led FAQ on every page, with answer-first wording that assistants can quote
- `sitemap.xml`, `robots.txt` (search and AI crawlers explicitly allowed), `llms.txt` summary for AI assistants

## Forms

Enquiries are emailed with Resend by the Cloudflare Worker in `worker/` (sender, recipients and allowed sites are in `worker/wrangler.toml`). Set `NEXT_PUBLIC_LEAD_ENDPOINT` to the deployed worker URL when building. Until it's set, forms open the visitor's email app with the enquiry filled in.

To deploy the worker (once): `cd worker && npm install && npx wrangler login && npx wrangler secret put RESEND_API_KEY && npx wrangler deploy`. Then build the site with the printed `https://zoomlion-lead.<you>.workers.dev` URL as `NEXT_PUBLIC_LEAD_ENDPOINT`. `apps-script/` is the older Google Sheets option and is no longer used.

## Develop & deploy

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # static site in out/
git push      # GitHub Actions builds and deploys to Pages
```
